Settings

Appearance

Theme for the probe's own interface — the selection outline, the info panel and the toolbar. Nothing on the page you are inspecting changes. System follows your operating system's light and dark setting, and switches with it.

Measuring

With an element selected, hold Option (Alt on Windows and Linux) and point anywhere to measure the spacing between them. These control how the measurements read and draw; changes apply to open pages immediately — even mid-measurement.

Editing

With an element selected, the pencil in the toolbar opens a panel that tunes it live and copies what changed. These control how much of that panel you see; changes apply to open pages immediately, even with the panel already open.

Deep shader capture

The panel's Advanced section tunes a WebGL canvas by attaching to its shader while you edit — which can miss one that drew a single frame before you got there. On, a small hook records which canvases receive WebGL programs from page load instead. It runs on every page, keeps what it sees inside that page, and nothing is read until you open the edit panel on a canvas — nothing is stored, and nothing leaves the browser either way.

Copying

What Copy Code and the edit panel's copy button put on the clipboard. The payload is a pointer — it names the construct you mean and then gets out of the way, so your own instruction stays the loudest thing in the prompt. Defaults are what the extension copied before this section existed.
